About This Project

This system implements the Hybrid TDA + Machine Learning framework proposed in our IEEE Xplore paper for maritime loan default prediction.

Research Problem

Traditional credit risk models evaluate shipping companies in isolation, missing interconnected network effects that drive systemic default risk in maritime finance.

Proposed Solution

A hybrid framework combining Topological Data Analysis for network feature extraction with four machine learning classifiers for accurate binary default prediction.

Dataset

150 maritime shipping company records with 13 financial and operational features across loan terms, vessel operations, and market conditions.

Best Model

XGBoost achieves the highest performance: Accuracy 0.9000, Precision 0.9412, Recall 0.8889, F1-Score 0.9143.

Framework Pipeline
1

Raw Dataset

150 maritime shipping company records with financial, operational, and market features.

2

Correlation Network Construction

Companies modeled as nodes. Pearson correlation creates weighted edges forming an inter-company network graph.

3

TDA Network Metrics

Four topological metrics extracted: Degree Centrality, Betweenness Centrality, Clustering Coefficient, and PageRank.

4

Pearson Feature Selection

Features ranked by linear correlation strength with the Default target variable.

5

ML Classification

Four classifiers trained: Logistic Regression, Decision Tree, Random Forest, and XGBoost.

6

Default / Non-Default Output

Binary classification — Default (1) when company fails to repay, Non-Default (0) when loan is repaid.
